# 📱 ReLance – Freelance Marketplace (UI/UX Case Study)

ReLance is a complete mobile freelancing marketplace concept focused on **human creativity**, **secure workflow**, and a **clean, modern UI/UX experience**.  
This project showcases a full end-to-end product design approach using Figma.

---

## ⭐ Features

- User Authentication (Sign In / Sign Up)  
- Home + Categories  
- Search Page + Filters  
- Search Results (Multiple layouts)  
- Service Details Page  
- Freelancer Profile  
- Chat / Messaging  
- Add New Service (with 3 Packages)  
- Wallet & Payments  
- Order Review  
- Order Tracking Flow  
- Ratings & Reviews  
- Notifications  
- Profile Settings  
- Identity Verification (ID Check)  
- Trust & Safety Page  
- Success Screens  
- Empty States  
- Onboarding Screens  
- Full Design System (Colors, Typography, Components, Icons)

---

## 🎨 Design Principles

- Clean and consistent visual style  
- Soft pastel color palette with purple gradients  
- Clear hierarchy and smooth UX flows  
- Accessible and scalable components  
- Realistic marketplace interactions  
- Human-first, no AI-generated content

---

## 🛠 Tools Used

- **Figma** (Auto Layout, Components, Variants, Prototyping)  
- **FigJam** for flow diagrams and planning
